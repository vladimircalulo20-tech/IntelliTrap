ABOUT THE PROJECT

About IntelliTrap

🦟

IntelliTrap is an AI-assisted mobile monitoring system designed to support the identification of visual indicators associated with possible mosquito breeding sites.

The system uses an ESP32-controlled mobile robot for movement, a smartphone camera for image capture, and a Teachable Machine image-classification model for AI-assisted assessment.

Note: AI results are preliminary assessments and do not confirm the presence of mosquito eggs or larvae. Physical verification is recommended.
